## Project Overview
This project proposes a small-office network simulated using Cisco Packet Tracer. It separates Administration, Sales, IT and Guest devices into VLANs, uses router-on-a-stick inter-VLAN routing, and demonstrates DHCP address allocation and DNS name resolution.

## Syllabus Mapping
- Unit I: DNS and network applications
- Unit III: IP addressing, routing and DHCP
- Unit IV: VLANs, switches, MAC addressing and LANs
- Practicals 6-8: DHCP and VLAN configuration in Cisco Packet Tracer
